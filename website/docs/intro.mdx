# Altcontainers

Altcontainers is a lightweight Java 17+ library for Docker container lifecycle management.

It handles image pulling, container creation, startup, readiness waiting, and cleanup — with automatic reaper-based resource reclamation when the JVM exits. The library ships as a shaded uber-JAR: its internal copies of docker-java, Jackson, Guava, Apache Commons, Bouncy Castle, and JNA are relocated under `nonapi.shaded.*` to isolate them from application dependencies.

```java
ContainerSpec containerSpec = ContainerSpec.builder("nginx:1.27")
    .exposePorts(80)
    .waitForHttpResponse(80)
    .build();

try (Container container = Container.create(containerSpec)) {
    int port = container.hostPort(80);
    // use http://localhost:<port>
}
```

## Features

- **Shaded uber-JAR** — docker-java, Jackson, Guava, Apache Commons, Bouncy Castle, and JNA are relocated under `nonapi.shaded.*` to isolate Altcontainers' internal copies from application dependencies; SLF4J is left unrelocated so applications can provide their own binding
- **Automatic cleanup** — integrated reaper destroys containers and networks when the JVM exits
- **Readiness waiting** — port probes, HTTP response checks, log message matching, and custom strategies
- **Network management** — create and destroy Docker bridge networks
- **Bind mounts** — read-write or read-only host directory mounts
- **Resource limits** — memory, CPU, `/dev/shm`, and Linux ulimits
- **Image pulling** — local image reuse, concurrent pull deduplication, and a configurable pull timeout
- **Retry with backoff** — configurable startup attempts with linear backoff

## Public API

All public types live in `org.altcontainers.api`.

- `Container` — create and destroy containers; runtime handle with `hostPort()`, `isRunning()`, `close()`
- `ContainerSpec` / `GenericContainerSpec.Builder` — immutable container configuration and its builder
- `Network` — create and destroy bridge networks; network handle for container-to-container communication
- `Wait`, `WaitStrategy`, `PortWaitStrategy`, `HttpWaitStrategy`, `LogWaitStrategy` — readiness strategies
- `StartupCheckStrategy` — startup check evaluated before readiness waits
- `OutputFrame` — raw container output frames with stream metadata
- `BindMount`, `Ulimit` — bind mount and resource-limit specifications
- `ContainerException` — runtime exception for lifecycle and configuration failures
- `Version` — library version information
